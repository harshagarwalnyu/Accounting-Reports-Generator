# Accounting Reports Generator — Frontend

Next.js 15 dashboard for the report generation system.

## Tech Stack
- Next.js (TypeScript)
- TailwindCSS
- Bun
- React Query
- Lucide Icons

## Setup
```bash
cd frontend
bun install
```

## Running
```bash
bun run dev
```

## Environment
Set `NEXT_PUBLIC_API_URL` to your backend URL (default: http://localhost:8000/api).
